Why Evakage?

The name combines Eva-, evoking evanescence — fading or disappearing — with kage (影), Japanese for shadow.

Evakage is built for temporary, end-to-end encrypted chat and file sharing. Messages and files are encrypted on your device; save files you want to keep.

Known devices

Devices are remembered by the fingerprint of their long-lived key the first time you connect. Deleting its stored relationship means it shows as new again, and its safety code is worth re-checking. Verify by comparing codes outside this app. Blocking a device stops exchanges with it in this browser.

Guide

  1. Open Evakage on both devices.
  2. Choose Connect, then scan the other device’s QR code or enter its code and choose Join.
  3. Select a device below to chat or share files.

For a group chat, create a room and share its code. Anyone with the code can join; login is only needed to create a room.
