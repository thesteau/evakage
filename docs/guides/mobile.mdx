## Install the app

Open your Evakage HTTPS URL, then:

| Device | Install |
| --- | --- |
| Android / Chrome / Edge | **Settings → Install**, or use the browser's install prompt (hover or tap the ⓘ beside *Install app* for help) |
| iPhone / iPad / Safari | **Share → Add to Home Screen** |

Installation is optional. The browser page works too.

## Keep transfers running

Keep Evakage open and the screen unlocked on both devices until the transfer finishes. Switching apps or locking the screen can interrupt it. Background transfers are not guaranteed.

Evakage requests a screen wake lock during transfers when supported. On return, it reconnects and checks its connections.

Large direct downloads can use substantial browser memory. Streamed relay saves reduce memory use when available, but physical-phone memory limits have not been measured.

## Share from another app

On supported Android and desktop Chrome/Edge installations, choose Evakage in the share sheet. Select a device or room to send shared files; shared text is placed in the composer.

- Share-sheet limit: **16 MiB**, including packaging.
- For larger files, use **Send file** inside Evakage. The default file limit is **512 MiB**.
- iOS does not support this web share-sheet integration.

To scan an invitation without leaving the installed app, use **Connect → Scan QR Code**. External QR scans may open the browser instead.

## Offline and updates

The installed app can open its interface offline, but it needs the server for signaling and relay delivery.

An update banner lets you choose when to reload. Finish transfers first: reloading clears in-memory conversations.
