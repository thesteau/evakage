## Install the app

Open your Evakage HTTPS URL, then:

| Device | Install |
| --- | --- |
| Android, or desktop Chrome/Edge | Choose **Settings → Install**, or follow the browser's install prompt. Hover over or tap the ⓘ beside **Install app** for help. |
| iPhone or iPad with Safari | Choose **Share → Add to Home Screen** |

Installation is optional. The browser page works too.

## Keep transfers running

Keep Evakage open and the screen unlocked on both devices until the transfer finishes. Switching apps or locking the screen can interrupt it. Background transfers are not guaranteed.

Evakage asks the browser to keep the screen awake during transfers when supported. When you return to the app, it reconnects to the server and checks its device connections.

Large direct downloads can use substantial browser memory. Streaming relay downloads to disk reduces memory use when available. Memory limits on physical phones have not been measured.

## Share from another app

On supported Android and desktop Chrome/Edge installations, choose Evakage from your system's share menu. Select a device or room to send shared files. Shared text appears in the message field, ready for you to send.

- Share-sheet limit: **16 MiB**, including packaging.
- For larger files, use **Send file** inside Evakage. The default file limit is **512 MiB**.
- iOS does not support this web share-sheet integration.

To scan an invitation without leaving the installed app, use **Connect → Scan QR Code** for a device, or the QR button next to **Join** in Rooms for a room. Either scanner accepts both kinds. External QR scans may open the browser instead.

## Offline and updates

The installed app can open its interface offline, but it needs the server for signaling and relay delivery.

An update banner lets you choose when to reload. Finish transfers first: reloading clears in-memory conversations.
