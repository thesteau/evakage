Already have an Evakage URL? Open it on both devices and skip to [Connect devices](#connect-devices).

## Host your own

With Docker installed:

```bash
git clone https://github.com/thesteau/evakage.git
cd evakage/deploy
cp .env.example .env
docker compose pull
docker compose up -d
```

Open `http://localhost:3712` on the host. Other devices need an HTTPS URL with a trusted certificate.

Behind a reverse proxy you control, set `TRUST_PROXY=1` in `deploy/.env` and preserve the public host header. See [deployment](/hosting/deployment) for setup and updates.

## Connect devices

1. Open the same Evakage URL on both devices.
2. On one device, show its private pairing code, or its QR code with the QR icon next to **Connect** in Devices.
3. On the other, choose **Connect**. Scan the QR or enter the code and choose **Join**.
4. Open the paired device to send a message or file.

Public advertised codes do not grant pairing. To confirm who you connected to, [compare safety codes](/guides/devices#verify-a-device).
