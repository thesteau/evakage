Already have an Evakage URL? Open it on both devices and skip to [Connect devices](#connect-devices).

## Host your own

With Docker installed:

```bash
git clone https://github.com/thesteau/evakage.git
cd evakage/deploy
cp .env.example .env
docker compose pull
docker compose up -d
```

Open `http://localhost:3712` on the host. Other devices need an HTTPS URL with a trusted certificate.

If you use a reverse proxy you control, set `TRUST_PROXY=1` in `deploy/.env` and preserve the public host header. Follow the [deployment guide](/hosting/deployment) for HTTPS setup, updates, and backups.

## Connect devices

1. Open the same Evakage URL on both devices.
2. On one device, choose the QR icon next to **Connect** in **Devices**. It shows that device's QR invitation and private pairing code.
3. On the other device, choose **Connect**. Scan the QR code, or enter the private pairing code and choose **Join**.
4. In **Devices**, choose **Open** beside the paired device to start a conversation.

Pairing requires the private invitation. The public code shown for an advertised device does not grant access. To confirm who you connected to, [compare safety codes](/guides/devices#verify-a-device).
